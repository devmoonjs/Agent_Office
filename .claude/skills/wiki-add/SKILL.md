# /wiki-add <주제>

주제를 받아 `20-Wiki/`에 정식 위키 노트를 작성한다.

## 절차

1. **중복 확인**: `20-Wiki/` 전체에서 같은 주제의 노트(제목/aliases)가 있는지 검색. 있으면 새로 만들지 말고 기존 노트를 보강한다.
2. **분류 결정**: concept(개념) / pattern(패턴) / tool(도구) 중 하나. 애매하면 concept.
3. **작성**: `90-Meta/templates/wiki-note.md` 구조 준수. 제목은 영문 kebab-case 파일명, frontmatter `aliases`에 한글명. **CLAUDE.md "문서 스타일" 규정 적용** (기술문서 톤).
   - "정의"와 "동작 원리"는 반드시 채운다 — 동작 원리는 실행 시점/데이터 흐름 등 메커니즘 수준으로 기술
   - "적용 예시"는 가능하면 사용자의 실제 코드(커밋)에서 가져오고 `파일:라인` 출처를 남긴다
   - "트레이드오프와 대안"에 언제 쓰면 안 되는지와 대체 기법 비교를 포함한다
   - `confidence`: 대화에서 충분히 다뤘으면 medium, 깊게 검증했으면 high
4. **연결**: 최소 2개의 `[[백링크]]` — 관련 노트가 없으면 스텁을 만들어서라도 연결한다.
5. **MOC 등록**: `20-Wiki/MOC-llm.md`의 해당 섹션에 링크 추가.
